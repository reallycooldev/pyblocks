# 🐍 PyBlocks Studio V5

A lightweight, offline-ready Python 3 coding studio, interactive 48-stage course, and `turtle` graphics playground built to run smoothly on phones, tablets, and school laptops.

### 🚀 Live Links
* **Cloudflare:** [pyblocks-studio.aiden-austin.workers.dev](https://workers.dev)
* **GitHub Pages:** [reallycooldev.github.io/pyblocks](https://github.io)

---

### ✨ Features
* **100% Offline Python & Graphics:** Powered by local Skulpt files (`skulpt.min.js` & `skulpt-stdlib.js`) with live `turtle` drawing and **Save PNG** artwork export.
* **🎓 48-Stage Learn Mode:** 6 full sections covering Print/Input, Variables & Math, Strings, Decisions, Loops & Lists, and Turtle Art—complete with automatic output grading and **No-Hint Section Tests**.
* **⚡ Smart Code Editor:** Clickable Python block templates with fill-in boxes, auto-closing brackets & quotes, smart indentation, `A-`/`A+` font zoom, and a red **Stop** button for infinite loops.
* **🎨 8 Custom Themes & Auto-Save:** Switch between **Blue**, **Midnight**, **Light**, **Matrix**, **Red**, **Purple**, **Ocean**, and **Amber**—your code, theme, and course progress save automatically in your browser.

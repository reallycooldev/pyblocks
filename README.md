# 🐍 PyBlocks Studio V7

A lightweight, offline-ready Python 3 coding studio, interactive Course Academy, and `turtle` graphics playground built to run smoothly on phones, tablets, and school laptops.

### 🚀 Live Links
* **Cloudflare:** [pyblocks-studio.aiden-austin.workers.dev](https://pyblocks-studio.aiden-austin.workers.dev)
* **GitHub Pages:** [reallycooldev.github.io/pyblocks](https://github.io)

---

### ✨ Features
* **🏠 3-Page Hub Architecture:** Cleanly separated into the **Main Menu (`index.html`)**, **Course Academy (`courses.html`)**, and **Free-Build Studio (`studio.html`)** with synced themes and progress across every page.
* **🎓 Course Academy & Unlockable Blueprints:** Complete all 48 stages of **Course 1: Python Fundamentals** (including No-Hint Boss Tests) to unlock **Course 1 Studio Blueprints** (`f-String`, `Dictionary {}`, `while` loops, `def` functions, `Random`, and `Turtle`).
* **100% Offline Python & Graphics:** Powered by local Skulpt files (`skulpt.min.js` & `skulpt-stdlib.js`) with live `turtle` drawing and **Save PNG** artwork export.
* **💡 Smart Error Translator & 🔍 Variable X-Ray:** Automatically translates Python tracebacks into plain-English fix tips and lets you inspect every variable's final value after running code.
* **⚡ Smart Code Editor:** Categorized Python block templates with multiple white fill-in boxes (`Tab` to jump between boxes), auto-closing brackets & quotes, smart indentation, `A-`/`A+` font zoom, and a red **Stop** button for infinite loops.
* **🎨 8 Themes + Custom Colour Picker:** Switch between **Blue**, **Midnight**, **Light**, **Matrix**, **Red**, **Purple**, **Ocean**, and **Amber**—or design and auto-save your own color scheme using the live **`🎨`** picker bar.

# PyBlocks Studio V2.0.1 🐍⚡

An offline-ready, browser-based **Python 3 IDE**, **120-Stage Quad-Course Academy**, and **Turtle Graphics Playground** powered by Skulpt — all in ~67 KB of pure HTML/CSS/JS.

## 🛠️ What's New in V2.0.1 (Patch Release)
- **Theme-Synced Turtle Canvas:** Centered `260×220` drawing canvas that automatically matches your active preset or custom theme (`var(--card)`) with crisp stroke rendering.
- **Smart Block Line Numbers & Syntax Highlighting:** Custom Spck-inspired Python 3 color palette (`input()`, `print()`, keywords, strings, numbers) with block-level line counting that skips blank and indented lines.
- **Interactive `input()` & Editor Controls:** Full browser prompt support for `input()`, plus dedicated **Clear Output**, **Clear Input**, and **Clear All** buttons.
- **Variable X-Ray & Toast Polish:** Fixed top-level variable inspection and separated **Studio Notice** alerts from **Achievement Unlocked!** trophy toasts.

## ✨ Core Features (V2.0)
- **Quad-Course Academy (120 Stages):**
  - **Course 1:** Python Fundamentals (48 Stages)
  - **Course 2:** Turtle Art & Geometry (24 Stages)
  - **Course 3:** Mini-Game Dev & Spy Ciphers (24 Stages)
  - **Course 4:** Retro Arcade & Text Adventures (24 Stages)
- **📖 Explain Function Live Sandbox:** Interactive overlay inside Courses to test `print()`, `variables`, `if/else`, `for`, `dict`, `random`, and `turtle` live with beginner rule tips.
- **Per-Section Blueprint Unlocks:** Defeat section bosses (`1.8`, `2.8`, `3.8`, etc.) to unlock reusable code blocks in Free-Build Studio, plus custom user-created blocks.
- **Theme-Synced Logo & Shareable Theme Codes:** Dynamic `PyBlocks` title colors + copy/paste `PBS2:...` theme sharing across all 8 presets and custom themes.
- **Mobile Quick-Symbol Bar:** One-tap `Tab`, `( )`, `[ ]`, `{ }`, `" "`, `:`, and `=` buttons above the editor.
